# 課題・保存機能

端末内保存とFirebase保存を追加しています。起動手順・制約は [保存機能の試し方](STORAGE.md) を参照してください。

通常のデバッグ起動では端末内に保存し、再起動後も復元します。Firebaseモードでは認証したアカウントごとに保存・共有します。本番Firebaseには未接続です。

先生は「課題」から作成・確認、生徒は「学習 → 課題提出」からテキスト回答、画像（JPEG・PNG）、PDFで提出します。添付は最大3ファイル、各10MiBまでで、先生がアプリ内で閲覧できます。提出30コイン、承認70コイン、再提出時の追加提出報酬なし。承認済みの変更はできません。

生徒の「学習 → 勉強モード」からAndroidのカメラ判定を開始し、終了後の記録を「学習記録」で確認できます。先生は「課題 → 生徒の学習記録」から集計を閲覧できます。生成AIアドバイスの接続は今後の実装です。
