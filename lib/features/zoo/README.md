# 動物園 MVP

- `domain/`: Flutter に依存しないマップ・動物定義と、個体の待機／移動ロジック。
- `data/`: アセット JSON の読み込み。
- `presentation/`: フレーム更新、ライフサイクル管理、画面・描画。
- `assets/zoo/world.json`: マップと初期表示する動物の定義。

## データと素材の変更

マップの `columns` / `rows` と `tiles` を一緒に変更すればマップを拡張できます。
各行の文字数は `columns`、行数は `rows` と一致させます。
`.` は草地、`=` は土の通路、`#` は石の通路、`~` は水辺です。背景タイルに衝突判定はなく、移動を制限するのは動物ごとの `movementArea` です。
`tileSize` は描画上の 1 タイルの大きさ（16 以上）。動物は 16×16 の仮スプライトで表示します。

`animals` は動物の定義です。ゲーム画面には確定した `ownedAnimalIds` に含まれる種だけを1匹ずつ表示します。未接続・未購入では動物は表示しません。

| フィールド | 意味 |
| --- | --- |
| `id` | 重複しない動物種 ID |
| `name` | 表示・アクセシビリティ用の名前 |
| `imagePath` | Flutter アセットの画像パス。null または読み込み失敗時は仮ドット絵 |
| `speed` | 1 秒当たりの移動タイル数（正数） |
| `movementArea` | 中心座標の移動範囲。left/top/right/bottom をタイル単位で指定 |
| `placeholderColor` | 仮素材の色。ARGB の 16 進文字列 |
| `evolutionIds` | 将来の進化先の動物種 ID。進化処理自体は未実装 |

原点はマップ左上で、右が X 正方向、下が Y 正方向です。
動物がマップからはみ出さないよう、移動範囲は各端から最低 0.5 タイル内側に設定します。
正式な PNG を追加する場合は `pubspec.yaml` の `assets` に登録し、`imagePath` を設定してください。
画像は補間なし、仮素材・背景はアンチエイリアスなしで描画し、通常は物理ピクセルの整数倍率に合わせます。

## 動作と今後の統合

各個体は 0.5〜2.5 秒待機し、矩形内のランダムな目的地まで定速移動します。
長時間フレームと復帰直後の移動ジャンプを防ぎ、バックグラウンドでは更新を停止します。
背景は動物の移動ごとには再描画しません。

定義（`AnimalDefinition`）と個体状態（`AnimalWalker.instanceId` / position）は分離しています。
購入の確定結果で所持状態を更新し、表示する個体を所持データから生成します。既存個体の位置は再生成せず保持します。
プロフィールは仮データです。所持金・課題状態はゲーム連携リポジトリから受け取った確定結果を表示します。未接続時の残高は「—」、明示的なデモ起動時は固定モックです。ショップはゲーム側の購入契約とモックに接続済みで、動物一覧は現在の所持個体を参照します。
モック購入は実装済みです。本番保存・本番決済、進化演出、学習検出との接続は行っていません。`study/` への依存もありません。

## 検証

リポジトリルートで `flutter analyze` と `flutter test` を実行します。
範囲内移動、速度、待機・移動の切り替え、JSON の不正設定、実アセットによる画面表示、仮ボタン、コンパクトな画面を検証します。

## ホーム画面の配置

- 上部: レベルアイコン・ゲスト名と確定残高（未接続時は「—」）。タップすると詳細シートを表示します。
- 中央: 動物園。ドラッグ・ピンチ、または右下の拡大・縮小ボタンで操作できます。
- マップ右上: 図鑑アイコンと現在の動物数。タップで動物一覧を表示します。
- 下部: ホーム・課題・その他。ホームはマップを全体表示に戻し、課題は受信した状態の閲覧、その他は動物一覧・ショップへのメニューを開きます。
- `presentation/zoo_chrome.dart`: ヘッダー・下部ナビ・詳細シートの共通枠。
- `presentation/zoo_viewport.dart`: カメラ操作・マップ上の操作ボタン。移動ロジックや JSON は変更しません。

上段の7つの素材は意味の割り当てが未定のため、通貨への割り当ては行っていません。
`study/` への依存、勉強の記録との接続はありません。ショップ購入・通貨消費は明示的なデモ起動時のモックで検証できます。

新仕様の接続契約とデモ起動方法: [ゲーム連携仕様](../../../docs/game_integration_contract.md)。

施設の配置は `world.json` の `facilities` で指定します。商品定義・条件・価格は `assets/zoo/shop_catalog.json` を参照してください。

## ゲーム側 UX（フェーズ4）

購入前に確認ダイアログを表示し、成功後は「動物園を見る」から戻れます。
結果不明の購入は同じゲーム画面内で再確認でき、ショップを閉じても再送キーを保持します。
動物はマップ上でタップ、または動物一覧から選んで詳細を開けます。立ち絵は追加していません。
詳細は上記の連携仕様書のフェーズ4を参照してください。

## 追加スプライトの表示

ウサギ・キツネ・シカ・進化キツネのマップ・一覧・詳細はユーザー提供の小型スプライトを使います。
`lib/features/animals/presentation/animal_art.dart` に表示 ID と素材の対応を集約しています。
個別の `imagePath` が設定されていればそちらを優先し、素材がない動物には従来の仮表示を残します。
ショップの池・森には池・木のアイコンを使い、マップの施設タイルや移動ロジックは維持しています。
新しい価格・動物の自動解放は追加していません。

## タイル・横柵（20261023.png）

地形描画は `presentation/terrain/` に分離しています。草・土・石・水を素材から描画し、境界パーツだけを回転します。
横道は土、縦道は石です。横柵は端・中間・ゲートをつなぎ、右端だけを左右反転します。縦柵は未提供のため表示しません。
下部ナビにはクリーム柄を薄く敷いています。[地形素材の説明](../../../docs/terrain_usage.md) を参照してください。

## UI改善

空の動物園にはショップへの案内を表示します。ズーム倍率はカメラの状態に追従します。
木製の課題ボタン・動物数表示・シート見出しに既存素材を使い、シートの見出しと閉じるボタンはスクロール中も残します。
ショップのカテゴリ切り替えは表示の絞り込みだけを行い、購入条件や残高計算を変更しません。
変更範囲と検証は [UI改善の記録](../../../docs/game_ui_polish.md) を参照してください。
