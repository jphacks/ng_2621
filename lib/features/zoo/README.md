# 動物園 MVP

- `domain/`: Flutter に依存しないマップ・動物定義と、個体の待機／移動ロジック。
- `data/`: アセット JSON の読み込み。
- `presentation/`: フレーム更新、ライフサイクル管理、画面・描画。
- `assets/zoo/world.json`: マップ・動物・施設の定義。

## データと素材の変更

マップの `columns` / `rows` と `tiles` を一緒に変更すればマップを拡張できます。
各行の文字数は `columns`、行数は `rows` と一致させます。
`.` は草地、`=` は土の通路、`#` は石の通路、`~` は水辺です。囲い・施設の配置時には地形との衝突を検証し、配置済み動物の歩行範囲は囲いの内側から生成します。
`tileSize` は描画上の 1 タイルの大きさ（16 以上）。動物は16×16の表示領域に提供素材を描画し、素材がない場合は仮表示を使います。

`animals` は動物の定義です。ゲーム画面には確定した `ownedAnimalIds` に含まれ、購入済み囲いに割り当てた種だけを1匹ずつ表示します。未接続・未購入では動物は表示しません。

| フィールド | 意味 |
| --- | --- |
| `id` | 重複しない動物種 ID |
| `name` | 表示・アクセシビリティ用の名前 |
| `imagePath` | Flutter アセットの画像パス。null または読み込み失敗時は種IDに対応する提供素材、なければ仮表示 |
| `speed` | 1 秒当たりの移動タイル数（正数） |
| `movementArea` | 旧定義の移動範囲。現在の配置済み動物は囲いの内側を使用 |
| `placeholderColor` | 仮素材の色。ARGB の 16 進文字列 |
| `evolutionIds` | 進化先の動物種ID。解放条件と購入は商品JSONで管理し、進化演出は未実装 |

原点はマップ左上で、右が X 正方向、下が Y 正方向です。
動物がマップからはみ出さないよう、移動範囲は各端から最低 0.5 タイル内側に設定します。
正式な PNG を追加する場合は `pubspec.yaml` の `assets` に登録し、`imagePath` を設定してください。
画像は補間なし、仮素材・背景はアンチエイリアスなしで描画し、通常は物理ピクセルの整数倍率に合わせます。

## 動作と今後の統合

各個体は 0.5〜2.5 秒待機し、矩形内のランダムな目的地まで定速移動します。
長時間フレームと復帰直後の移動ジャンプを防ぎ、バックグラウンドでは更新を停止します。
背景は動物の移動ごとには再描画しません。

定義（`AnimalDefinition`）と個体状態（`AnimalWalker.instanceId` / position）は分離しています。
購入の確定結果で所持状態を更新し、表示する個体を所持データから生成します。既存個体の位置は再生成せず保持します。
プロフィールは仮データです。所持金・課題状態はゲーム連携リポジトリから受け取った確定結果を表示します。未接続時の残高は「—」、明示的なデモ起動時は固定モックです。ショップはゲーム側の購入契約とモックに接続済みで、動物一覧（図鑑）は定義済みの全キャラを表示します。未所持キャラは元のUIシートのロックアイコン付きで表示し、詳細は開けません。所持済みキャラだけ詳細・配置操作を利用できます。
画面は `StudyRepository` 経由で課題・勉強モード・学習記録へ遷移します。ローカルデモは課題報酬・学習報酬と購入を同じ状態へ反映します。Firebase側の囲い・配置・追加建築物への対応はアカウント対応で追加済みです。本番デプロイは別途必要で、進化演出は未実装です。

## 検証

リポジトリルートで `flutter analyze` と `flutter test` を実行します。
範囲内移動、速度、待機・移動の切り替え、JSON の不正設定、実アセットによる画面表示、仮ボタン、コンパクトな画面を検証します。

## ホーム画面の配置

- 上部: レベルアイコン・ゲスト名と確定残高（未接続時は「—」）。タップすると詳細シートを表示します。
- 中央: 動物園。ドラッグ・ピンチ、または右下の拡大・縮小ボタンで操作できます。
- マップ右上: 図鑑アイコンと現在の動物数。タップで動物一覧を表示します。
- 下部: ホーム・学習（先生は課題）・その他。下部ナビは中央の画面遷移中も残ります。ホームは動物園へ戻り、学習は学習機能、その他はプロフィール・ログアウトなどの設定です。
- `presentation/zoo_chrome.dart`: ヘッダー・下部ナビ・詳細シートの共通枠。
- `presentation/zoo_viewport.dart`: カメラ操作・マップ上の操作ボタン。移動ロジックや JSON は変更しません。

上段の7つの素材は意味の割り当てが未定のため、通貨への割り当ては行っていません。
課題・学習報酬との連携は端末内デモで検証できます。起動・保存モードの設定は `../study/STORAGE.md` を参照してください。

新仕様の接続契約とデモ起動方法: [ゲーム連携仕様](../../../docs/game_integration_contract.md)。

施設の配置は `world.json` の `facilities` で指定します。商品定義・条件・価格は `assets/zoo/shop_catalog.json` を参照してください。

## ゲーム側 UX（フェーズ4）

購入前に確認ダイアログを表示し、成功後は「動物園を見る」から戻れます。
結果不明の購入は同じゲーム画面内で再確認でき、ショップを閉じても再送キーを保持します。
動物はマップ上でタップ、または動物一覧から選んで詳細を開けます。立ち絵は追加していません。
詳細は上記の連携仕様書のフェーズ4を参照してください。

## 追加スプライトの表示

ウサギ・キツネ・シカ・進化キツネのマップ・一覧・詳細はユーザー提供の小型スプライトを使います。
`lib/features/animals/presentation/animal_art.dart` に表示 ID と素材の対応を集約しています。
個別の `imagePath` が設定されていればそちらを優先し、素材がない動物には従来の仮表示を残します。
ショップの池・森には池・木のアイコンを使い、追加建築物には専用シート `zoo_buildings.png` を使います。
新しい価格・動物の自動解放は追加していません。

## タイル・横柵（20261023.png）

地形描画は `presentation/terrain/` に分離しています。草・土・石・水を素材から描画し、境界パーツだけを回転します。
横道は土、縦道は石です。横柵は端・中間・ゲートをつなぎ、右端だけを左右反転します。縦柵と角は追加シート `20261024_3.png` を使用します。
下部ナビはレンガ背景、「その他」などの背景はクリーム柄です。[地形素材の説明](../../../docs/terrain_usage.md) を参照してください。

## UI改善

空の動物園にはショップへの案内を表示します。ズーム倍率はカメラの状態に追従します。
木製の課題ボタン・動物数表示・シート見出しに既存素材を使い、シートの見出しと閉じるボタンはスクロール中も残します。
ショップのカテゴリ切り替えは表示の絞り込みだけを行い、購入条件や残高計算を変更しません。
変更範囲と検証は [UI改善の記録](../../../docs/game_ui_polish.md) を参照してください。

## ショップ専用画面

ショップは独立したルートで開きます。動物・施設タブ、検索、絞り込み、グリッド一覧と商品詳細を分離しています。
購入コントローラーは動物園が保持し、結果不明の購入を再確認できます。
[一覧の構成と拡張方法](../../../docs/shop_browsing.md) を参照してください。

## 施設の配置・移動

購入済みの池などを、ショップの商品詳細または「ホーム → 囲い・施設 → 施設の配置・移動」から編集できます。
選択枠のドラッグ・タイル選択・プレビュー・確定・キャンセルに対応し、保存が成功した位置だけを動物園へ反映します。
池・森の未編集の初期配置は維持し、追加建築物は購入後に配置します。配置は確定スナップショットへ反映します。通常の端末内デモは永続化し、メモリ用リポジトリを明示した場合は起動中だけ保持します。
[配置ルール・保存契約・施設追加手順](../../../docs/facility_placement.md) を参照してください。

## 購入式の囲いと動物配置

固定エリアの柵は描画せず、購入した囲いを表示します。面積1マス5コイン、拡張時は増えた面積分のみ課金します。
動物は購入後に一覧から囲いを指定します。歩行範囲は囲いの内側で、旧 `movementArea` は配置済み個体には使いません。
池の四隅・辺には追加シートの1/4・1/2水タイルを回転して使います。
[操作・連携契約・拡張箇所](../../../docs/enclosure_system.md) を参照してください。

### 図鑑のページ表示

動物一覧は正方形カードを等間隔で並べ、前後のページボタンで切り替えます。スクロールはしません。カードには `world.json` の動物定義順に `No.01` から番号を表示し、名前・ロック中文字は表示しません。既存番号を維持する場合、動物定義は末尾に追加してください。未所持の場合は動物アイコンの中央に元UIシートのロックを重ね、詳細を開く操作を無効にします。読み上げ用の名前・未所持状態は保持します。所持済みの場合だけ詳細・配置操作を利用できます。

ホーム上部に「動物園・ショップ・囲い／施設」の切り替えを設けています。主要な購入・配置操作はここから進めます。カメラのリセットはマップの「全体を表示」ボタンを使用します。[共通ナビとショップ整理](../../../docs/navigation_and_shop.md)。

Firebaseモードの表示名・データはアカウントのUIDに結び付きます。設定と登録は [アカウント資料](../../../docs/accounts.md) を参照してください。

通常動物19種類と研究対象8種類の定義・価格・進化条件は
[動物追加の説明](../../../docs/animal_roster.md)を参照してください。
kiwiは入手条件未定のため、画像のみ登録しています。
