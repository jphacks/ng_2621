# 学習と動物園の連携・体験改善

## 担当境界と受け渡し

ゲーム担当は目標・演出・動物の反応・配置UI・研究所を実装する。
勉強判定、課題、認証、Functionsは共同開発者の担当。既存APIの読み取りと購入窓口を利用し、残高を画面側で増減しない。

| データ | 既存の受け取り口 | ゲーム側の扱い |
| --- | --- | --- |
| 所属・生徒ID、revision、確定残高、所持品、配置 | GameRepository.watchGameState / GameSnapshot | 認証されたセッションのスナップショットを使用 |
| 課題報酬 | GameSnapshot.rewards / RewardReceipt.transactionId | 初回ロードは履歴扱い。新規確定取引だけ演出 |
| 自習報酬 | StudyRepository.loadStudyRecords / StudyRecord.rewardCoins | 保存済み記録を読み取り、記録ID単位で重複排除。時間から独自に報酬を算出しない |
| 商品・解放条件 | ShopRepository.loadCatalog / ShopCatalog | 残高・所有・条件を確定スナップショットと照合 |
| 購入 | ShopPurchaseController / ShopRepository.purchase | 通常の確認・再送・購入結果UIを再利用 |

新しい連携元は、ゲーム向けの確定報酬イベント（所属・生徒ID、安定した取引ID、正の確定額、報酬種別）を返す。学習終了だけの通知、クライアント申告額、残高の差分だけでは報酬確定と判断しない。
目標と演出済みIDは所属・生徒IDごとに端末へ保存する。これはゲームのUI設定であり、コイン台帳ではない。保存先未注入のテスト・メモリデモでは起動中だけ保持する。

## フェーズと完了条件

1. **連携契約**：上記DTO・モック・重複排除を定義。別ユーザーのイベントを拒否する。
2. **目標動物**：図鑑から購入可能な動物を目標に設定し、「あと何コイン」と条件を表示。設定を保存・解除できる。
3. **報酬演出**：履歴を初回に再生せず、新しい確定報酬のみコイン演出を表示。表示だけで残高を変更しない。通知が他画面に隠れないようホームで表示する。
4. **反応と配置**：動物タップ・報酬後のリアクション、ドラッグ時の半透明表示、確定時の端末標準音・振動。OSの設定に従い、動きを減らす設定にも配慮する。
5. **研究所**：カタログの進化先・解放条件を表示し、既存の購入確認へ進む。元の動物を消費しない。研究所を所持・配置して利用する。
6. **Firebase通し確認**：配置編集の原子的な取引、正規価格・条件、所持・衝突・権限・冪等性の検証がバックエンドに必要。ゲーム側モックの成功と本番接続の成功は区別する。

## 共同開発者への依頼

- 学習保存成功後に `loadStudyRecords` が安定した記録ID・生徒ID・確定 `rewardCoins` を返すこと。0コインは演出しない。
- 初回ロード時に過去の記録を取得できること。取得失敗時は成功したときに履歴の基準を作り、過去分を新規報酬として扱わない。
- Firebaseの動物園ドキュメントに `GameSnapshot.layout` のDTOを保持し、`PurchaseRequest.layoutEdit` をCallableへ渡すこと。
- サーバーで `zoo_layout`、追加建築物、面積差額を検証すること。参考：[囲い契約](enclosure_system.md)、[建築物](building_sprites.md)。
- 学習報酬・購入・配置の同時実行を一つの確定スナップショットへ反映し、revisionを単調増加させること。

## 検証

各フェーズで契約・状態遷移とUIをテストし、最後に解析・全テストを実行する。
Androidでのカメラ・音・振動、本番Firebaseの認証・別端末復元は、実機と接続環境で別途確認する。

## 操作して確認する順番

1. 図鑑右上のチェックボタン、または「ホーム → 囲い・施設 → 目標の動物」で未所持の動物を選ぶ。ホームの目標表示をタップして変更・解除できる。
2. 学習／課題画面で報酬を確定し、ホームへ戻る。ごほうび表示を閉じるか、ショップへ進む。
3. 目標の商品を購入し、図鑑から囲いに配置する。所持確定後は目標達成と表示する。
4. 動物をタップして反応を確認し、施設・囲いの選択枠をドラッグ、確定する。
5. ショップで研究所を購入・配置し、「ホーム → 囲い・施設 → 研究所」から進化条件を確認、通常の購入確認で解放する。

目標と演出設定の保存に失敗した場合は目標選択画面でエラーを表示する。メモリデモでは再起動時に消える。
演出履歴の初回取得に失敗しても学習画面への遷移は止めず、初回成功の履歴を新規報酬として一括再生しない。
研究所は進化商品の案内・購入窓口であり、現在のショップから進化商品を直接購入する経路も維持する。
