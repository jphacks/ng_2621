# カラフルな操作ボタン

`20261024_2 (3).zip` 内の64×64画像を、既存の同名素材とは別に
`assets/sprites/color_buttons.png` として追加しています。元の画像は変更していません。

- メニュー名・見出し：従来の `WoodPanel`。
- 購入・確定などの主要操作：緑。
- 画面移動・未選択のタブ：水色。選択中のタブ：緑。
- 補助操作・クリックできるカード：白または黄色。
- 操作不可：灰色。未所持の図鑑には従来どおりロックも重ねます。
- 情報表示だけの枠や画面背景：従来の素材を維持。

`PixelUiTheme` が標準の Filled/Elevated/Outlined/Text/IconButton に適用します。
ログイン画面もアプリ全体のテーマで対応し、認証・学習・購入処理は変更しません。
独自の InkWell カードは `ColorActionPanel` を使用します。
色を明示する場合は `PixelUiTheme.colorfulButtonStyle(ButtonPalette.green)` を指定します。

画像は各16×16セルで、左から通常・押下のペアです。
黄・緑／水色・橙／桃・青／白・灰の8色を定義しています。
`ColorButtonPanel` は押下画像の透明行を除いて9分割で繰り返し描画し、
輪郭を最近傍で2倍表示します。ラベルやアイコンは維持し、色だけで操作を区別しません。

## 通常時の装飾と文字の視認性

通常画像の下部には2ピクセルの台座と縁・角の装飾があります。
上下を同じ4ピクセルで分割すると、下のハイライトが中央に混ざり横線になります。
通常時は上4行・下7行を外周に固定し、残った無地の部分だけを繰り返します。
押下時は従来の上下4行を維持します。素材自体は加工していません。

木枠と操作ボタンには共通の `PixelTextOutline` を適用します。
木枠・明るいボタンは黒系文字＋白縁、青・灰色や無効ボタンは白文字＋黒縁です。
8方向の1論理ピクセル・ぼかしなしの文字影で輪郭を作ります。
文字・読み上げツリーを複製せず、文字サイズやレイアウトを維持します。
通常の文字継承に加え、内部のMaterial/ListTile向けのテキストテーマにも局所的に適用します。

## クリーム枠を使う画面

図鑑のマス・ショップの商品カードは旧素材のクリーム四角に戻しています。
「囲い・施設」の購入・配置・研究所などの行にも同じ枠を使います。
`SpriteTile.panelStyle` を指定するとその行だけ枠を変更でき、他の画面には影響しません。
文字のアウトライン・操作時のInkWellフィードバックは維持します。

アカウント・所持コインのヘッダーはホームの3区分（動物園／ショップ／囲い・施設）と
その詳細画面で共通表示します。通知・目標バナーだけを動物園に限定し、一覧の領域を確保します。

## 即時操作と学習メニュー

閉じる・戻る・＋／−などのIconButtonは、`legacyButtonStyle(gray)` で
旧灰色枠を固定表示します。回答へのボタンは旧クリーム枠です。
学習メニューと設定の行はクリーム四角に揃えています。
大きな操作ボタンには引き続きカラフルな素材を使い、文字の輪郭は双方で維持します。
