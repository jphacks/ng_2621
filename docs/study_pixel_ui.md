# 学習画面のドット絵UI

作業ブランチ: `feat/study-pixel-ui`

## 変更範囲

- アプリ起動・端末内デモ・Firebase接続経路の共通フォントを、同梱のDotGothic16へ統一。
- 学習メニューをスプライトのカードと矢印で表示。
- 課題一覧・作成・提出・提出状況・勉強モード・学習記録・添付プレビューに、共通の `StudyScaffold` と `StudyAppBar` を適用。
- 背景は既存のクリームパターン、見出しは木製枠、情報カードはクリーム丸枠。入力欄は文字を読みやすい無地のクリーム色。
- 各種ボタンは既存の `PixelUiTheme` を再利用。カメラ映像・画像・PDF本体の表示品質は変更しない。
- 戻る、本とペン、右矢印、追加、添付削除に既存スプライトを使用。

判定、カメラ制御、課題・報酬・保存・通信処理は変更しない。
戻る操作はFlutter標準のBackButtonとPopScopeを維持し、アイコンだけ差し替える。
先生側の課題画面も表示部品のみ統一する。

## 追加で必要なアイコン

対応する素材がない操作は、意味が異なるスプライトで代用せず標準アイコンを維持。

| 用途 | 素材の候補名 |
| --- | --- |
| 勉強モード（時計・タイマー） | study_timer |
| 学習記録（グラフ） | study_records |
| 再読み込み（循環矢印） | refresh |
| 締切選択（カレンダー） | calendar |
| 添付画像・写真を選ぶ | image_gallery |
| PDF書類 | pdf_document |
| ファイル添付（クリップ） | attach_file |
| 添付を開く／拡大表示 | open_preview |

操作用アイコンは16×16の透明セルが既存UIに合わせやすい。
選択や展開の状態を持つチェックボックス・プルダウン・カレンダー内部はFlutter標準部品を維持する。
認証画面は今回は共通フォントのみ変更し、アイコン・レイアウトの変更対象には含めない。

## 確認手順

1. 生徒として起動し、学習メニューの3項目を開く。
2. 課題の入力・添付・提出と、先生側の提出確認を操作する。
3. Androidでカメラ準備→勉強開始→終了・保存を操作し、学習記録を開く。
4. 文字サイズを大きくして、スクロール・戻る・入力欄・ボタンを確認する。

自動テストでは課題・添付・報酬・学習の既存フローに加え、320×568・文字倍率1倍／2倍での画面遷移、フォント、背景、戻るアイコンを確認する。
カメラの実動作とAndroid実機の見た目は実機確認が必要。

静的解析は `flutter analyze` で指摘なし。
既存のフロー147件と新規UIテスト2件を確認する。
