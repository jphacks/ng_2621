# 共通ナビとショップの整理

## 画面の入口

下部の「ホーム・学習・その他」を共通シェルに置き、中央のNavigatorで画面を切り替える。
購入確認・カレンダーなどの一時ダイアログを除き、商品詳細・配置・学習画面でも下部ナビを表示する。

| 下部ナビ | 中央の表示 |
| --- | --- |
| ホーム | 動物園・ショップ・囲い／施設を切り替えるゲームの入口 |
| 学習（先生は課題） | 生徒の学習メニュー、または先生の課題一覧 |
| その他 | プロフィール、現在の役割、ログアウト、開発時の連携デモ |

ホーム上部の「ショップ」から動物・施設を直接購入できる。
「囲い・施設」には施設購入、囲いの購入・拡張、施設配置、研究所、図鑑、目標選択を配置した。
主要なゲーム操作はその他に入れない。
「ホーム」は動物園へ戻る操作で、カメラのリセットはマップの「全体を表示」ボタンで行う。

## ショップの情報の優先順位

1. 残高は枠を付けない情報表示。
2. 「動物／施設」は選択中のタブを木製の枠で強調。
3. 検索は白い入力欄として表示し、ボタンと区別。
4. 「購入可能のみ」「購入済みを隠す」は「絞り込み」から開く別パネルへ移動。
5. 適用中の絞り込み件数を入口に表示。検索・分類・商品グリッドの仕組みは維持。

## 実装上の境界

- 共通シェルと内部Navigatorは `zoo_screen.dart`、観測とホームタブ・メニューページは `zoo_navigation.dart`。
- 学習・課題の画面実装、判定、報酬、保存、認証、Functionsは変更しない。既存画面を中央のNavigatorへ接続する。
- 移動は `maybePop` を使い、既存のPopScopeを尊重する。学習終了・保存待ちを強制的に飛ばさない。
- ShopScreenは埋め込み表示にも対応。検索・分類・スクロールと購入コントローラーを保持する。
- ホーム以外ではゲームの更新を止め、中央の学習画面やショップを優先する。
- 小さい画面・大きい文字ではホーム情報欄をスクロールできる高さに制限。キーボードによるリサイズはシェルで一度だけ行い、中央のScaffoldで二重に縮めない。
- 狭い高さやキーボード表示時は、一時的にホーム内タブやショップの補助見出しを省略し、入力・商品一覧・下部ナビの場所を確保する。

## 確認内容

`test/features/zoo/zoo_navigation_test.dart` で次を検証する。

- 商品詳細と学習記録で下部ナビを操作できる。
- 画面を切り替えてもショップの検索を保持する。
- 囲い・施設の購入へホームから直接進める。
- 追加の絞り込みは必要なときだけ開く。
- 保存をブロックするPopScopeをタブ切り替えで強制的に閉じない。
- キーボード表示中も検索と下部ナビが使え、二重リサイズによるオーバーフローがない。

課題の提出・承認、報酬、ショップ購入、囲い配置、図鑑などの既存テストも併せて実行する。

「その他」は図鑑と区別するため歯車アイコンに変更。対応するドット絵素材は未提供のため、標準の設定アイコンを仮使用する。
