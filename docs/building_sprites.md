# 建築物スプライトとクリーム丸枠

提供された64×64シートは `assets/sprites/zoo_buildings.png` として保存。
同名だった既存の `20261024_2.png`（動物・アイコン）は保持。

切り出しは `ZooBuildingPart` に集約し、透明部分も含むセルで配置する。
クリーム丸枠は左上32×16、研究所は右上32×32、ベンチ・植木は中央左の各16×16、噴水・フラワーアーチは下段の各32×32。
最近傍描画を使用。丸枠は `SpritePanelStyle.creamRound` でサイズに応じて角を保持し、ゲーム内確認ダイアログに適用。

## 建築物

| ID | 名前 | 仮価格 | 占有マス |
| --- | --- | ---: | --- |
| laboratory | 研究所 | 400 | 2×2 |
| bench | ベンチ | 100 | 1×1 |
| topiary | 植木 | 120 | 1×1 |
| fountain | 噴水 | 300 | 2×2 |
| flowerArch | フラワーアーチ | 250 | 2×2 |

価格は `assets/zoo/shop_catalog.json`、表示・占有サイズ・配置候補は `assets/zoo/world.json` で管理。
研究や回復などの効果は未実装。現在は装飾施設であり、1種類1個を所有できる。

ショップの施設カテゴリで購入し、「ホーム → 囲い・施設 → 施設の配置・移動」から場所を選んで確定する。
購入直後は未配置で、既存の動物園や囲いに自動配置しない。移動は無料。
建物同士、囲い、通路、水辺との重なりは既存の配置ルールで拒否する。
未配置の新建築物は土地を予約しない。池・森の従来の配置は維持。

ローカルデモの購入・配置・スナップショット保存に対応。
Firebase側のカタログと配置取引APIへの反映は共同開発者との連携が必要で、今回変更していない。

## 木製見出し

「その他」「動物一覧」など共通シートの閉じるボタンを木製見出しの外側に配置。
枠とボタンの重なりを避け、閉じる操作とアクセシビリティ用ラベルは維持する。

## 検証

- 新シートの全可視ピクセルが切り出しに含まれ、2倍描画時のRGBAが原画に一致すること。
- 5施設の購入・再送・無料移動・保存復元・無効配置の拒否。
- 未配置時の非表示、確定後のマップ表示、プレビュー時に確定座標を書き換えないこと。
- 木製見出しと閉じるボタンの領域が重ならないこと。
