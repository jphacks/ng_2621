# 動物追加・研究進化（暫定バランス）

既存素材と新規シートを合わせ、通常動物19種類・研究対象8種類を登録しています。
既存の価格・所持IDを維持し、新規価格は仮値です。
データは `assets/zoo/shop_catalog.json` / `world.json`、サーバー版は
`functions/catalog.json` / `game_world.json` です。両側のデータ一致をテストしています。

## 研究所の進化

研究所（既存価格400コイン）を購入・配置したうえで、進化元を所持すると解放できます。
費用は進化ごとに支払い、元の動物は残ります。確認ダイアログを経由します。
通常ショップからは研究対象を除外し、研究所にのみ表示します。

| 進化先 | 必要な動物 | コイン |
| --- | --- | ---: |
| 進化キツネ | キツネ | 800 |
| 炎狐 | キツネ | 500 |
| 雪狐 | キツネ | 500 |
| 氷狐 | 雪狐 | 900 |
| 雷狐 | 炎狐 | 900 |
| 霊狐 | キツネ | 1000 |
| 伝説の狐 | 炎狐・雪狐・氷狐・雷狐・霊狐 | 2500 |
| 氷帝ペンギン | ペンギン | 900 |

`acquisition: research` と `requiredAnimalIds` / `requiredFacilityIds` で設定します。
アプリ・モック・Functionsで進化元・施設所有・施設配置・残高を検証します。
同一リクエストの再送は二重決済せず、解放済み動物の別リクエストも拒否します。
Firebase利用時は更新したFunctionsのデプロイが必要です。この作業では本番にデプロイしません。
