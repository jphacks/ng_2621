# 発表デモチュートリアル

## 起動

Android StudioのRun ConfigurationのAdditional run argsに以下を追加します。

```text
--dart-define=ZOOSTUDY_PRESENTATION=true
```

PowerShellで実機を指定する場合：

```powershell
C:\flutter\bin\flutter.bat run -d RFCY201JHGF --dart-define=ZOOSTUDY_PRESENTATION=true
```

端末IDは `flutter devices` で確認してください。`--release` でもこの明示的なデモ起動に対応します。
フラグを変えた後はアプリを停止して再起動します。
このフラグはFirebaseや端末保存データを開く前に発表デモへ入ります。
通常起動でも「その他 → 発表デモチュートリアル」から開始できます。

## 発表ルート

1. 先生役で「今日の学習をふり返ろう」を配布。
2. 生徒役で用意された回答を提出（編集も可）：30コイン。
3. 先生役で回答を確認・承認：追加70、合計100コイン。
4. ショップでウサギを選び、購入を確認。
5. デモ用に無料で用意した4×4の囲いへ配置し、動物が動き始める。
6. 明示された体験用1,500コインで施設・進化体験に進む。
7. 池を購入し、実際の配置画面で確定。ドラッグで移動も可。
8. キツネ・研究所を購入し、研究所を配置。
9. 研究所で炎狐を選び、進化の確認。元のキツネは残る。
10. 炎狐をウサギと同じ囲いに配置。
11. 図鑑を開き、番号と未所持のロックを確認。閉じる。
12. 「育った園を見る」で、27種類・4区画・施設を備えた完成イメージへ。上部の残高やナビを隠した全画面で締めくくる。
    「自由に見てみる」で通常のゲーム画面へ戻り、「もう一度体験する」で最初から再開できる。

案内のボタンはその時点で必要な画面へ移動します。
購入・配置・進化は既存画面で行い、結果が確定すると案内が自動で進みます。
「？」で現在の操作説明を確認できます。「はじめから」でデモだけを初期化できます。
通常アプリから開いた場合は×ボタンで元のアプリに戻れます。
文字が大きい場合、案内欄をスクロールまたは折りたたんで一覧領域を確保できます。

## 説明上の区別

- **実処理**：課題配布・提出・承認は既存のローカルStudyRepository実装を再利用し、報酬30＋70を計算。購入・配置・進化も既存のゲーム処理を使用。
- **デモ設定**：最初の囲い、後半の1,500コイン、最後の育った動物園は体験用に用意したもの。通常の課題報酬ではない。
- **最終景**：「完成イメージ」と表示。動物や施設をデモ用に追加し、実アカウントで解放した結果とは区別する。報酬履歴と残高は追加しない。
- **保存しない**：実アカウント、Firebase、既存の端末データを変更しない。終了・再起動・「はじめから」で消える。通常アカウントの初期囲い・残高も変更しない。
- **任意の機能**：勉強モードや学習記録は学習タブから試せるが、カメラの許可・認証・外部通信を必須ルートに入れない。
- 単一端末で先生役・生徒役を交代する。複数端末間の本番同期をこのデモで実施したと説明しない。

施設・研究の購入額は池200＋キツネ250＋研究所400＋炎狐500＝1,350コイン。
体験用1,500コインから150コイン残り、初回の課題報酬100コインはウサギに使用します。

## 実装の範囲

`lib/features/game/demo/` にサンドボックス、手順判定、案内UI、起動画面を配置。
`ZooScreen` にデモ専用の案内と画面への誘導を追加。
`AppBootstrap` に明示フラグによる起動経路を追加。
学習担当のコード、認証、Functions、Security Rulesは変更していません。
カタログ・報酬額・通常のゲーム保存処理も変更していません。
