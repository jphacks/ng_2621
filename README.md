# ZooっとStudy(ずーっとスタディ)略:ずースタ

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
### 自習の時間を動物園を育てる時間に
ZooっとStudy（ずースタ）は、日々の自習を通じて自分だけの動物園を育てていく、学習支援アプリケーションです。

学習時間や集中度を記録・可視化し、その成果を動物の解放や動物園の発展につなげることで、学習を継続する楽しさと達成感を提供します。
### 背景(製品開発のきっかけ、課題等）
毎日自主的に勉強を続けようとしても，モチベーションを維持することが難しく，ついスマートフォンを触ってしまい，勉強に集中できないことがある！
また、勉強の成果はすぐに目に見えるものではなく、勉強の成果や達成感を実感しにくいことも，学習習慣が定着しない原因の一つだと考えられる．

そこで，勉強時間や集中度を可視化するとともに，ゲームの要素を取り入れることで，楽しみながら継続的に学習できる仕組みを作りたいと考え，本製品の開発を企画した．

単に学習時間を記録するだけではなく、「勉強した時間が、自分だけの動物園として形に残る」 という体験を通じて、学習そのものに新しい楽しさを生み出すことを目指す。

### 製品説明（具体的な製品の説明）
ZooっとStudyは、学習時間の記録と動物園の育成を組み合わせた学習支援アプリケーションである。

ユーザーはアプリを通じて自習を行い、学習時間や集中度に応じた報酬を獲得する。獲得した報酬を利用することで、新しい動物を解放したり、動物園を発展させたりすることができる。

動物にはそれぞれ異なる解放条件や進化の関係が存在し、学習を積み重ねることで、より多くの動物との出会いが生まれる。

また、動物の進化は元の動物を置き換えるものではなく、新たな動物をコレクションに追加する仕組みを想定している。これにより、学習を続けるほど動物園がにぎやかになり、自分の努力の積み重ねを視覚的に実感できる。
### 特長
#### 1. 自習の時間が動物園を育てる時間に
学習時間や集中度を記録し、その成果をゲーム内の報酬へと変換する。

勉強すること自体が動物園を育てる行動となるため、日々の学習に新しい目的と達成感が生まれる。
#### 2. 自分だけの動物園を発展できる
学習を通じて新しい動物を解放し、自分だけの動物園を発展させることができる。

動物同士には進化や解放に関するつながりが存在し、複数の動物が関係する特別な解放条件なども構想している。

単純に動物を増やすだけではなく、動物同士の関係を探索する楽しさを提供する。
#### 3. レアな動物を集めるためにさらに自習時間を増やす
動物ごとに異なる解放条件やレアリティを設けることで、コレクション要素を充実させる。

珍しい動物との出会いや新しい進化先の発見を、次の学習へのモチベーションにつなげる。
### 解決出来ること
#### 学習を継続するためのモチベーション不足

学習時間を動物園の成長へと結びつけることで、勉強を続けるための楽しみや目標を提供する。

#### 日々の学習成果を実感しにくいこと

学習の積み重ねを記録するだけでなく、動物の解放や動物園の発展として視覚化することで、努力の成果を実感しやすくする。

#### 学習習慣の定着が難しいこと

新しい動物の解放やコレクションの充実といった継続的な目標を設けることで、自発的に学習へ取り組むきっかけを作る。
