# ZooっとStudy(ずーっとスタディ)略:ずースタ

[![ZooっとStudy 紹介動画](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
### 自習の時間を動物園を育てる時間に
ZooっとStudy（ずースタ）は、自習の記録や先生からの課題への取り組みを、自分だけの動物園の育成につなげる学習支援アプリケーションです。

生徒は学習や課題提出でコインを獲得し、動物・施設を購入して動物園に配置できます。先生は課題の配布、提出内容の確認、承認・再提出依頼を行います。

### 背景(製品開発のきっかけ、課題等）
日々の自主学習は、成果がすぐに見えにくく、モチベーションを保つことが難しい場合があります。また、先生には課題の配布や提出状況の確認といった作業が発生します。

そこで、学習の積み重ねを動物園の成長として楽しめる仕組みと、先生・生徒の課題提出の流れを組み合わせました。

「勉強した時間や課題への取り組みが、自分だけの動物園として形に残る」という体験を目指しています。学習習慣や提出率の改善効果は、今後の検証課題です。

### 製品説明（具体的な製品の説明）
ZooっとStudyは、先生向けの課題管理と、生徒向けの学習記録・2Dドット絵の動物園を組み合わせたアプリです。

課題は初回提出で30コイン、先生の承認で追加70コインを獲得します。再提出では提出報酬を重複付与しません。テキスト回答に加え、画像・PDFの添付に対応しています。

Androidの勉強モードでは、カメラで顔または教材・手元を確認して判定方式を自動選択します。判定対象となった時間を同じ日の利用分で合算し、2分につき1コイン、1日最大30コインを終了・保存時に確定します。日付は日本時間の0時で切り替わります。姿勢や映り方は参考情報であり、理解度や集中度を測定・証明するものではありません。映像・写真・音声は学習記録として保存・送信しません。

動物園ではコインを使って動物、池、研究所、ベンチ、植木、噴水、フラワーアーチなどを購入します。柵は囲い1区画として幅・高さを指定し、面積1マスにつき5コインで購入・拡張できます。複数の動物を任意の囲いに配置すると、その範囲内で移動と待機を繰り返します。施設と囲いはマップ上の選択枠をドラッグして移動でき、確定するまで保存しません。

図鑑は正方形のカードを等間隔に並べたページ方式です。全動物を番号付きで表示し、未所持の動物にはロックアイコンを重ねます。所持済みの動物だけ詳細・配置操作を利用できます。通常ショップに19種類、研究所に8種類の動物を登録しています。研究所では狐の派生や氷帝ペンギンを元の動物を消費せず解放できます。研究所の購入・配置と進化元の所持が必要です。[動物一覧・暫定価格と進化条件](docs/animal_roster.md)。研究所以外の建築物固有の効果や複雑な進化演出は未実装です。

アカウントモードでは、Firebase AuthenticationのUIDごとに残高・所持品・囲い・配置・目標を保存します。生徒はメール／パスワードと招待コードで登録し、先生は管理者が登録します。Firebaseエミュレーターで登録・購入・配置・再ログインを検証済みですが、本番プロジェクトへのデプロイは別途必要です。[設定と起動手順](docs/accounts.md)。

図鑑から目標の動物を選ぶと、ホームに必要な残りコイン数を表示します。新しい確定報酬はコインが財布へ向かう演出と動物のリアクションで通知し、同じ取引は重複演出しません。目標・演出履歴は生徒ごとの端末設定として保存します。

ホーム内の「動物園・ショップ・囲い／施設」から主要なゲーム操作へ進みます。下部の「ホーム・学習・その他」は中央の画面を切り替えても表示し、その他には設定・プロフィールをまとめています。ショップの追加条件は「絞り込み」から開きます。

発表時は通信・ログイン不要の[ガイド付きデモ](docs/presentation_tutorial.md)で、課題から動物園の成長まで順番に体験できます。

### 特長
#### 1. 自習の時間が動物園を育てる時間に
学習記録と課題への取り組みをコインにつなげ、動物園を育てるきっかけを作ります。課題の提出報酬と承認報酬を分け、生徒が現在の状態を確認できます。

#### 2. 自分だけの動物園を発展できる
動物や施設を購入し、池や建築物の配置、囲いの購入・拡張、動物の割り当てを行えます。配置の重なりや範囲外を検証し、不正な位置では確定できません。

UIと動物園には提供されたドット絵素材を使用し、拡大時もピクセルがぼやけない描画を行います。日本語フォントは同梱のDotGothic16を使用します。

#### 3. レアな動物を集めるためにさらに自習時間を増やす
図鑑に未所持の動物も表示し、次に集める目標を見つけられるようにしています。ショップには動物・施設の分類、検索、購入条件に応じた絞り込みがあります。

複数の動物が関係する解放条件、種類の追加、レアリティなどは今後の拡張対象です。

### 解決出来ること
#### 学習を継続するためのモチベーション不足
学習や課題提出を動物園の成長に結びつけ、継続して取り組む目標を提供します。

#### 日々の学習成果を実感しにくいこと
学習時間・獲得コインの記録と、動物の収集・配置を通じて、取り組みの積み重ねを振り返れます。

#### 学習習慣の定着が難しいこと
自習と課題提出の両方を支援し、新しい動物を集める楽しさを学習のきっかけにつなげることを目指しています。効果は利用者による検証が必要です。

## 開発技術
### 活用した技術
#### API・データ
* Firebase Authentication、Cloud Firestore、Cloud Functions、Cloud Storage。接続にはFirebase設定とバックエンドの準備が必要です。
* 動物・マップ定義：`assets/zoo/world.json`、商品定義：`assets/zoo/shop_catalog.json`。バックエンドの正規カタログは別管理です。
* 保存モード・Firebase設定・エミュレーターの手順は [STORAGE.md](lib/features/study/STORAGE.md) を参照してください。

#### フレームワーク・ライブラリ・モジュール
* Flutter / Dart：アプリUI、動物園描画、ゲームロジック。
* camera、google_mlkit_face_detection、ultralytics_yolo：Androidの学習判定。
* shared_preferences、path_provider、idb_shim：端末側データ保存。image_picker、file_selector、pdfrx：添付選択・表示。
* DotGothic16：オフライン利用できる同梱フォント。[ライセンス](assets/fonts/OFL-DotGothic16.txt)。

依存関係の取得と確認は、プロジェクト直下で実行します。

```sh
flutter pub get
flutter analyze
flutter test
```

ローカルデモはデバッグ実行専用です。Android StudioでAndroid端末を選択して起動するか、`flutter devices` で端末IDを確認して次を実行します。

```sh
flutter run -d <Android端末ID> --dart-define=ZOOSTUDY_STORAGE=local
```

#### デバイス
* Android：生徒向けアプリとカメラによる勉強モードの主対象。
* Web：先生向け課題管理など。カメラによる勉強判定はAndroid版のみ対応。
* iOS：Flutterのプロジェクト構成は保持していますが、実機動作は未検証です。Windowsデスクトップ用プロジェクトは含みません。

### 独自技術
#### ハッカソンで開発した独自機能・技術

* スプライトを使った共通UI：[建築物と枠](docs/building_sprites.md)、[学習UIと不足素材](docs/study_pixel_ui.md)。

学習機能班との接続仕様と検証範囲：[体験改善フェーズ](docs/game_experience_phases.md)、[Firebase担当への接続仕様](docs/game_backend_handoff.md)。

画面の入口とショップの整理：[共通ナビの説明](docs/navigation_and_shop.md)。

アカウントの新規登録・保存：[アカウント設定](docs/accounts.md)。通常の起動は端末内デモで、アカウント機能には `ZOOSTUDY_STORAGE=emulator` またはFirebase設定を指定します。
