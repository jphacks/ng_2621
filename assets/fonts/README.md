# DotGothic16

取得日: 2026-10-24。実行時のフォント取得や追加パッケージは不要です。

`pubspec.yaml` の `DotGothic16` ファミリーとして登録し、ゲームの `PixelUiTheme` に適用しています。
`ZooFont.registerLicense()` はFlutterのライセンス一覧にも原文を登録します。
認証・課題管理ルートのテーマ設定は変更していません。
